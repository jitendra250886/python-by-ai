# Advanced Python Course - Index

## Course Overview
This advanced course explores expert-level Python concepts, performance optimization, design patterns, and concurrent programming. Designed for developers ready to master Python's most powerful features and write production-grade code.

## Prerequisites
- Completion of Intermediate course or equivalent experience
- Strong understanding of OOP, decorators, and generators
- Experience with Python projects and debugging
- Familiarity with testing and package management

## Course Structure

### Module 1: Advanced OOP & Design Patterns (Lessons 01-05)
- **01_metaclasses_advanced.ipynb** - Metaclass programming, class factories
- **02_descriptors_properties.ipynb** - Descriptor protocol, property implementation
- **03_abstract_base_classes.ipynb** - ABC module, interface design
- **04_design_patterns_creational.ipynb** - Singleton, Factory, Builder patterns
- **05_design_patterns_structural.ipynb** - Adapter, Decorator, Facade patterns

### Module 2: Functional Programming Advanced (Lessons 06-08)
- **06_closures_scope.ipynb** - Closures, nonlocal, scope resolution
- **07_functional_tools.ipynb** - functools, itertools, operator module
- **08_partial_curry.ipynb** - Partial application, currying, composition

### Module 3: Concurrency & Parallelism (Lessons 09-14)
- **09_threading_basics.ipynb** - Threading module, thread safety
- **10_multiprocessing.ipynb** - Process-based parallelism, Pool
- **11_concurrent_futures.ipynb** - ThreadPoolExecutor, ProcessPoolExecutor
- **12_asyncio_basics.ipynb** - Async/await, event loop, coroutines
- **13_asyncio_advanced.ipynb** - Async context managers, async generators
- **14_async_patterns.ipynb** - Task management, gathering, timeouts

### Module 4: Performance Optimization (Lessons 15-18)
- **15_profiling_timing.ipynb** - cProfile, timeit, memory profiling
- **16_optimization_techniques.ipynb** - Algorithm optimization, caching
- **17_memory_management.ipynb** - Memory model, garbage collection, slots
- **18_cython_numba.ipynb** - Code compilation, performance acceleration

### Module 5: Advanced Data Structures (Lessons 19-21)
- **19_trees_graphs.ipynb** - Tree structures, graph representations
- **20_heaps_priority_queues.ipynb** - heapq module, priority queues
- **21_custom_data_structures.ipynb** - Implementing custom containers

### Module 6: Metaprogramming (Lessons 22-25)
- **22_introspection.ipynb** - inspect module, runtime analysis
- **23_dynamic_code_execution.ipynb** - eval, exec, compile
- **24_code_generation.ipynb** - Dynamic class/function creation
- **25_ast_manipulation.ipynb** - Abstract syntax trees, code transformation

### Module 7: Advanced I/O & Networking (Lessons 26-28)
- **26_async_networking.ipynb** - Async HTTP, aiohttp
- **27_socket_programming.ipynb** - TCP/UDP sockets, network protocols
- **28_database_async.ipynb** - Async database operations, ORMs

### Module 8: Security & Best Practices (Lessons 29-31)
- **29_secure_coding.ipynb** - Input validation, injection prevention
- **30_cryptography_basics.ipynb** - Hashing, encryption, cryptography module
- **31_code_security.ipynb** - Security auditing, common vulnerabilities

### Module 9: Testing & Quality (Lessons 32-34)
- **32_advanced_testing.ipynb** - Mocking, fixtures, parametrization
- **33_property_based_testing.ipynb** - Hypothesis, property testing
- **34_test_coverage_ci.ipynb** - Coverage analysis, CI/CD integration

### Module 10: Design Patterns Behavioral (Lessons 35-37)
- **35_observer_strategy.ipynb** - Observer and Strategy patterns
- **36_command_iterator.ipynb** - Command and Iterator patterns
- **37_state_template.ipynb** - State and Template patterns

### Module 11: Advanced Topics (Lessons 38-40)
- **38_protocols_structural.ipynb** - Structural subtyping, Protocol class
- **39_context_vars.ipynb** - Context variables, async context
- **40_advanced_packaging.ipynb** - Setup.py, wheels, PyPI publishing

### Module 12: Projects & Practice (Lessons 41-42)
- **41_advanced_exercises.ipynb** - Complex problem-solving exercises
- **42_advanced_projects.ipynb** - Advanced projects (async web server, etc.)

## Learning Objectives
By the end of this course, students will be able to:
- Master metaclasses and metaprogramming
- Implement design patterns appropriately
- Write concurrent and parallel code effectively
- Optimize Python code for performance
- Build scalable, production-ready applications
- Implement advanced data structures
- Write secure, maintainable code
- Apply advanced testing strategies
- Work with async I/O and networking
- Publish and distribute Python packages

## How to Use These Materials
1. Complete Intermediate course before starting
2. Read theoretical concepts carefully
3. Practice with code examples extensively
4. Complete challenging exercises
5. Build the advanced projects
6. Review performance considerations
7. Study real-world codebases for patterns

## Estimated Time
- Total: 80-100 hours
- Per lesson: 2-3 hours
- Recommended pace: 2-3 lessons per week (more time for practice)

- Contribute to open-source projects
- Build production applications
