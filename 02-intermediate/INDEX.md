# Intermediate Python Course - Index

## Course Overview
This intermediate course builds upon Python fundamentals, introducing advanced concepts, object-oriented programming, and practical tools for real-world development. Each lesson is provided as a Jupyter notebook for interactive learning and web platform integration.

## Prerequisites
- Completion of Beginner course or equivalent knowledge
- Understanding of basic Python syntax, data structures, and functions
- Familiarity with control flow and basic programming concepts

## Course Structure

### Module 1: Advanced Object-Oriented Programming (Lessons 01-04)
- **01_classes_deep_dive.ipynb** - Class design, attributes, methods, class vs instance
- **02_inheritance_polymorphism.ipynb** - Inheritance, method overriding, super()
- **03_encapsulation_abstraction.ipynb** - Private/protected attributes, property decorators
- **04_magic_methods.ipynb** - Dunder methods (__init__, __str__, __repr__, etc.)

### Module 2: Advanced Data Structures (Lessons 05-08)
- **05_list_comprehensions.ipynb** - List comprehensions, nested comprehensions
- **06_dict_set_comprehensions.ipynb** - Dictionary and set comprehensions
- **07_generators_iterators.ipynb** - Generator functions, yield, iterator protocol
- **08_collections_module.ipynb** - namedtuple, defaultdict, Counter, deque

### Module 3: Functional Programming (Lessons 09-11)
- **09_lambda_functions.ipynb** - Lambda expressions, map, filter, reduce
- **10_decorators_basics.ipynb** - Function decorators, wrapping functions
- **11_advanced_decorators.ipynb** - Decorators with arguments, class decorators

### Module 4: File Operations & Data Formats (Lessons 12-15)
- **12_advanced_file_handling.ipynb** - Context managers, binary files, file operations
- **13_json_handling.ipynb** - Working with JSON data, parsing, serialization
- **14_csv_excel_operations.ipynb** - CSV module, reading/writing spreadsheets
- **15_pickle_serialization.ipynb** - Object serialization with pickle

### Module 5: Error Handling & Debugging (Lessons 16-18)
- **16_advanced_exceptions.ipynb** - Custom exceptions, exception hierarchies
- **17_logging_debugging.ipynb** - Logging module, debug techniques
- **18_testing_basics.ipynb** - Unit testing with unittest, pytest introduction

### Module 6: Working with APIs & Web (Lessons 19-21)
- **19_http_requests.ipynb** - Requests library, GET/POST, API integration
- **20_web_scraping.ipynb** - BeautifulSoup, HTML parsing, ethical scraping
- **21_rest_api_basics.ipynb** - REST principles, consuming APIs

### Module 7: Regular Expressions (Lessons 22-23)
- **22_regex_fundamentals.ipynb** - Patterns, matching, searching
- **23_regex_advanced.ipynb** - Groups, lookahead, substitution

### Module 8: Virtual Environments & Packages (Lessons 24-25)
- **24_virtual_environments.ipynb** - venv, pip, requirements.txt
- **25_package_management.ipynb** - Creating packages, __init__.py, distribution

### Module 9: Advanced Topics (Lessons 26-28)
- **26_context_managers.ipynb** - with statement, __enter__, __exit__
- **27_metaclasses_intro.ipynb** - Type system, basic metaclasses
- **28_type_hints.ipynb** - Type annotations, mypy, static type checking

### Module 10: Projects & Practice (Lessons 29-30)
- **29_intermediate_exercises.ipynb** - Practice problems covering all topics
- **30_intermediate_projects.ipynb** - Mini-projects (API client, web scraper, etc.)

## Learning Objectives
By the end of this course, students will be able to:
- Design and implement complex class hierarchies
- Use advanced Python features (decorators, generators, comprehensions)
- Handle various file formats and data serialization
- Work with APIs and web scraping
- Write testable, maintainable code with proper error handling
- Use regular expressions for text processing
- Manage Python environments and packages
- Apply functional programming concepts
- Build intermediate-level applications

## How to Use These Materials
1. Complete the Beginner course first
2. Open notebooks in Jupyter Lab/Notebook or VS Code
3. Read explanations and run code cells sequentially
4. Experiment with code examples
5. Complete exercises at the end of each lesson
6. Build the mini-projects to reinforce learning
7. For web platform: convert notebooks to markdown with live execution

## Estimated Time
- Total: 60-70 hours
- Per lesson: 2-3 hours
- Recommended pace: 3-4 lessons per week
