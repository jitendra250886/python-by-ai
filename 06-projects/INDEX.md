## How to Use
- Open a project folder and read its `README.md` first.
- Install dependencies from `requirements.txt`.
- Implement functionality in `src/` following the TODOs.
- Add and run tests from `tests/`.
- Use `solutions/` for reference implementations if/when they are added.
