# Content Generation Guide

This guide explains how to generate and update all course content.

## Generators
- `project_scripts/generate_beginner_notebooks.py`
- `project_scripts/generate_intermediate_notebooks.py`
- `project_scripts/generate_advanced_notebooks.py`
- `project_scripts/generate_libraries_notebooks.py`
- `project_scripts/generate_applications_content.py`
- `project_scripts/generate_project_templates.py`
- `project_scripts/generate_all_content.py`

## Typical Commands
```bash
python project_scripts/generate_all_content.py --section all
python project_scripts/generate_all_content.py --section advanced
python project_scripts/update_content.py libraries
```
