# Beginner Python Course - Index

## Course Overview
This beginner course covers Python fundamentals from scratch. Each lesson is provided as a Jupyter notebook (.ipynb) that can be converted to markdown for web publishing with interactive code execution capabilities.

## Prerequisites
- No prior programming experience required
- Basic computer literacy
- Python 3.8+ installed

## Course Structure

### Module 1: Getting Started (Lessons 01-03)
- **01_introduction_to_python.ipynb** - What is Python, installation, and first program
- **02_variables_and_data_types.ipynb** - Variables, numbers, strings, booleans
- **03_basic_operators.ipynb** - Arithmetic, comparison, logical operators

### Module 2: Control Flow (Lessons 04-06)
- **04_conditional_statements.ipynb** - if, elif, else statements
- **05_loops_part1.ipynb** - for loops and iteration
- **06_loops_part2.ipynb** - while loops and loop control (break, continue)

### Module 3: Data Structures (Lessons 07-10)
- **07_lists.ipynb** - List creation, indexing, slicing, methods
- **08_tuples.ipynb** - Tuples and immutability
- **09_dictionaries.ipynb** - Key-value pairs and dictionary methods
- **10_sets.ipynb** - Sets and set operations

### Module 4: Functions (Lessons 11-13)
- **11_functions_basics.ipynb** - Defining functions, parameters, return values
- **12_function_scope.ipynb** - Local vs global scope, scope rules
- **13_advanced_functions.ipynb** - Default arguments, *args, **kwargs, lambda

### Module 5: Strings and Files (Lessons 14-16)
- **14_string_manipulation.ipynb** - String methods, formatting, f-strings
- **15_file_handling.ipynb** - Reading and writing files
- **16_error_handling.ipynb** - Try-except blocks, exceptions

### Module 6: Object-Oriented Programming Intro (Lessons 17-18)
- **17_classes_and_objects.ipynb** - Class basics, attributes, methods
- **18_oop_fundamentals.ipynb** - __init__, self, simple inheritance

### Module 7: Practice and Projects (Lessons 19-20)
- **19_coding_exercises.ipynb** - Practice problems covering all topics
- **20_beginner_projects.ipynb** - Small projects (calculator, to-do list, etc.)

## Learning Objectives
By the end of this course, students will be able to:
- Write and execute Python programs
- Use variables, data types, and operators
- Implement control flow with conditionals and loops
- Work with Python's built-in data structures
- Create and use functions
- Handle files and errors
- Understand basic OOP concepts
- Build simple Python applications

## How to Use These Materials
1. Open notebooks in Jupyter Lab/Notebook or VS Code
2. Read explanations and run code cells sequentially
3. Modify code examples to experiment
4. Complete exercises at the end of each lesson
5. For web platform: notebooks will be converted to markdown with live code execution

## Estimated Time
- Total: 40-50 hours
- Per lesson: 2-3 hours
- Recommended pace: 3-4 lessons per week
