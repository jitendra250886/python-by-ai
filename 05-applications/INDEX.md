# Applications Course - Index

## Course Overview
This level focuses on real-world Python applications and end-to-end use cases. Each application is organized as a mini-project with a dedicated folder, main notebook, and supporting files.

## Prerequisites
- Completion of Beginner and Intermediate levels (or equivalent experience)
- Familiarity with core libraries (see `04-libraries/INDEX.md`)

## Course Structure

### Module 1: Web Applications
- `web/` – Practical web apps (e.g., blog, dashboard, auth demo)

### Module 2: Data Analysis Applications
- `data-analysis/` – Data pipelines, dashboards, reports

### Module 3: Machine Learning Applications
- `ml/` – Training, evaluating, and serving ML models

### Module 4: Automation & Scripting
- `automation/` – Bots, schedulers, file/process automation

### Module 5: Desktop Applications
- `desktop/` – GUI tools and utilities

## Learning Objectives
By the end of this level, students will be able to:
- Design and build complete applications using Python
- Integrate multiple libraries and frameworks in a single project
- Structure codebases for maintainability and reuse
- Connect applications to external services (APIs, databases)
- Package and prepare applications for deployment

## How to Use These Materials
- Use `project_scripts/generate_applications_content.py` to create or refresh example application notebooks.
- Open the main notebook in each application folder to follow its tutorial and implementation.
- Extend the templates with your own features and experiments.
